# Customer Purchase Prediction System

## Overview

This project is a Machine Learning-based Customer Purchase Prediction System that predicts whether a customer is likely to make a purchase based on behavioral and demographic features. The system applies data preprocessing, feature engineering, and classification algorithms to analyze customer purchasing patterns.

## Objectives

* Analyze customer behavior data
* Predict purchase decisions
* Improve marketing strategies through predictive analytics
* Compare machine learning classification models

## Features

* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Customer Purchase Prediction
* Model Evaluation
* Confusion Matrix Visualization
* Performance Comparison

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Machine Learning Algorithms

* Logistic Regression
* Random Forest Classifier

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Feature Encoding
4. Train-Test Split
5. Model Training
6. Model Evaluation
7. Customer Purchase Prediction

## Evaluation Metrics

* Accuracy Score
* Precision
* Recall
* F1-Score
* Confusion Matrix
